# LibreCelik

LibreCelik (Слободни Челик) is a free and open-source smart card reader for documents issued by the Republic of Serbia. Supports electronic ID cards, vehicle registration documents, health insurance cards, and generic PKCS#15 tokens.

**Documentation & downloads:** [librescrs.github.io](https://librescrs.github.io)
