# What a tag of this repository publishes as release assets. One glob per
# line, then the one-line description the downloads page renders.
#
# This file is the single place that answers "what do we publish". One script
# holds it true, three times: --wired proves the release workflow calls it at
# all; --staged compares this list against the files actually staged, in the
# step before `gh release create`; --published <tag> compares it against the
# release that exists. Changing what the workflow publishes without changing
# this file fails the release before it is created.

LibreCelik-*-macos.dmg        universal macOS build (x86_64 + arm64); not Apple-signed or notarised
librecelik_*.orig.tar.gz      the deterministic source tarball
sbom-linux.cdx.json           CycloneDX bill of materials for the AppImage
sbom-macos.cdx.json           CycloneDX bill of materials for the DMG
SHA256SUMS                    checksums over every other asset in this release
